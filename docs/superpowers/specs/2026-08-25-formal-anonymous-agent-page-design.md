# 正式匿名智能体页面设计规格

## 目标

把 EducationMind 从“固定比赛演示站”调整为可以直接运行、可以嵌入其他平台、且不依赖登录系统的正式匿名学习智能体：所有学习者状态来自当前匿名身份产生的真实行为，课程目录可以预置，但不得再预置某个学习者的掌握度、证据、计划或考试结果。

本轮不建设账号、密码、教师角色或 RBAC。匿名标识只用于区分学习档案，不构成身份认证或授权凭据。

## 方案比较与选择

### 方案 A：继续使用一个固定公共学习者

改动最少，但所有访问者共享画像、考试和对话上下文，既不真实也无法嵌入其他平台。拒绝采用。

### 方案 B：立即接入登录和用户系统

隔离最完整，但超出“暂时不做登录”的明确范围，还会引入账号安全、找回、授权和隐私治理。拒绝采用。

### 方案 C：宿主注入身份，浏览器匿名身份兜底（采用）

宿主平台可以在页面脚本加载前注入一个不含个人信息的 opaque learner ID、课程 ID 和 API 地址；独立访问时，前端生成 `anon:<uuid>` 并持久化在浏览器 localStorage。这样既能保持无登录体验，也能让平台自行决定如何映射它的用户，同时避免所有访客共用一个演示账号。

用户已经明确授予实现取舍权并要求不再询问，因此本规格视为在该授权范围内批准执行。

## 产品形态

### 完整学习站

保留首页、我的学习、学习诊断、知识空间、学习空间、反思、考试中心、学习工坊、学习档案、设置和能力说明。删除 `/demo`、`/showcase` 及其页面、故事化比赛组件和入口文案。

### 独立智能体页

新增 `/#/agent`。该入口只呈现小涟智能体工作区，不显示完整学习站的侧轨导航，适合 iframe 或 WebView。它与 `/#/xiaolian` 复用同一个会话组件、语音输入输出、能力选择、工具轨迹和来源展示，避免形成两套行为不同的聊天实现。

### 设置与关于

关于页只说明当前真实能力、数据边界和开发者入口。设置页展示匿名会话方式、课程上下文与隐私边界，不展示未实现的登录配置。任何“比赛展示”“三分钟演示”“单学习者演示”文案都从当前产品界面撤除。

## 匿名学习上下文

新增独立的运行时配置与匿名会话模块。

配置优先级从高到低为：

1. `window.__EDUCATIONMIND_CONFIG__` 中宿主注入的合法值；
2. Vite 构建环境中的公开 API 地址；
3. 浏览器 localStorage 中已有匿名 learner ID；
4. 当前浏览器首次生成的 `anon:<uuid>`。

`courseId` 默认使用正式内置课程目录中的 `course-os`。宿主 learner ID 和 course ID 只允许有限长度的字母、数字、点、下划线、冒号和连字符；API 地址只允许 `http:`、`https:` 或同源相对地址。非法配置不进入 API 请求。

localStorage 只保存随机匿名标识，不保存姓名、手机号、邮箱或语音。语音识别继续使用浏览器能力：转写文本经用户确认后才发送；原始音频不上传到 EducationMind 后端。

## 前端数据流

所有原来引用固定 `DEMO_LEARNER_ID` 和 `DEMO_COURSE_ID` 的页面、组件和 Zustand action，统一读取已解析的 active learner context。页面请求、学习证据、计划、练习、考试、档案和智能体对话因此自然隔离到当前匿名身份。

API 客户端从运行时配置读取 `apiBaseUrl`。空地址继续使用同源 `/api`，便于统一域名部署；独立智能体页可以由宿主指定跨域 API。

组件不会在请求失败时创建替代画像、虚构掌握度或伪造回答。空档案显示“尚未形成证据”，网络错误显示可重试状态。

## 后端真实化

### 课程目录 Seed

启动 Seed 只创建课程、知识点、课程材料和内置考试元数据。它不创建任何 learner ID，也不写入掌握度基线、学习证据、计划、考试作答或对话。

`seed_demo_data`、`DEMO_LEARNER_ID`、`DEMO_MASTERY_BASELINE` 等生产符号全部撤除。需要固定基线的自动化测试在 `tests` 内部建立测试夹具，不能再依赖生产 Seed 伪造学习者状态。

### 模型服务

配置完整的 OpenAI-compatible 服务时调用真实外部模型。配置不完整时，Provider 状态为 `unavailable`，不再构造 Mock LLM 输出；导师服务可以返回由真实课程检索结果、画像和计划计算出的确定性基础辅导，并在 API/UI 中明确标为 `fallback`。服务状态不得泄露 API Key、Authorization 或完整内部地址。

### 跨域部署

新增 `EDUCATION_CORS_ORIGINS`，以逗号分隔明确允许的宿主 Origin。默认只允许常用本地开发 Origin，不使用带凭据的通配符。正式部署必须配置实际宿主 Origin。

## 旧演示数据退出

代码变更不能在应用启动时静默删除数据库。提供一个一次性迁移工具，默认只盘点精确 learner ID `demo-user-001` 的关联记录；显式 `--apply` 时先生成 SQLite 备份，再按依赖顺序删除该学习者数据并复查。它不得删除课程目录、知识点或其他 learner ID。

本地运行库执行迁移前后都要记录文件路径、大小、修改时间、备份路径和删除计数。自动化测试始终使用临时数据库，不能触碰根目录或 `apps/api` 下的运行库。

## 错误处理与安全边界

- 匿名 learner ID 是数据分区键，不是安全凭据；公开互联网部署仍应由宿主网关限制访问和速率。
- 无登录版本不宣称具备教师/学生权限隔离、监考、防作弊或跨设备账号同步。
- 外部模型、网络搜索或资源生成未配置或失败时显示真实失败/降级状态，不返回伪造成功。
- iframe 宿主负责配置允许嵌入的 CSP/frame-ancestors，并将 API Origin 加入后端 CORS allowlist。
- 浏览器刷新保持同一匿名档案；清除站点数据会创建新档案，这是无登录模式的预期限制。

## 测试与验收

### 前端

- 先写失败测试，覆盖匿名 ID 首次生成、稳定复用、宿主配置优先、非法配置拒绝、API base URL 和路由清单。
- 验证 `/demo`、`/showcase` 不再注册，`/#/agent` 存在且不渲染完整学习星轨。
- 验证小涟请求、考试、练习、计划和档案使用 active learner context。
- 全量执行 Vitest、`pnpm check` 和 `pnpm build`。

### 后端

- 先写失败测试，证明新数据库启动后只有课程目录、没有任何学习者掌握度。
- 验证未配置 LLM 时状态为 `unavailable`，回答明确标为 fallback；配置完整时仍选择真实 Provider。
- 验证 CORS 只允许配置的 Origin。
- 验证迁移工具 dry-run 不写库、apply 必须备份且只删除精确演示 learner。
- 全量执行 pytest，并比较两份运行 SQLite 在测试前后的元数据。

### 浏览器

同时验证完整站和 `/#/agent` 的桌面与窄屏布局、首次匿名空画像、一次真实交互、刷新后身份稳定、未配置模型提示、语音支持/不支持状态、控制台错误、失败请求和网络状态。Live2D 必须在真实浏览器中确认可见和稳定；加载失败时不显示旧头像回退。

## 明确不做

- 登录、注册、账号找回、教师/学生 RBAC；
- 将匿名 ID 宣称为认证机制；
- 自动删除未知或其他学习者数据；
- 在仓库提交 Live2D 受限资产、密钥或生产数据库；
- 为了画面完整而补造画像、考试结果、搜索结果或模型回答。
