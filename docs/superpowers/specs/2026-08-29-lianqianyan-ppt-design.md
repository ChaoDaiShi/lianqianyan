# 《链千言》产品说明 PPT 设计说明

## 目标

制作一份 20 页、16:9、可编辑的《链千言》创新赛道产品说明 PPT，面向竞赛评委，帮助评委理解链千言如何以 Learning Evidence 为核心，把学习诊断、动态规划、陪伴学习、练习复述和状态更新组织成一个持续闭环。

## 传播主线

学生产生学习行为 → 系统形成学习证据 → 小涟理解学习状态 → 决定下一步行动 → 陪学生继续学习。

全 deck 分为五章：

1. P2–P3：学生为什么仍然缺少持续判断，而不只是缺少答案；
2. P4–P8：链千言如何理解学习并依据证据动态调整；
3. P9–P16：小涟如何在一次专注学习中完成讲解、练习、复述、验证与自然陪伴；
4. P17–P18：Tool、MCP、Agent、RAG、Application Services 与数据层如何协同；
5. P19–P20：用开发过程和产品证据证明系统已经从 0 到 1 做出来。

## 视觉方案

采用模板跟随的混合方案：

- 保留模板 PPT 的 16:9 比例、页眉导航、科技线条、章节节奏和可复用版式骨架；
- 将模板原有政策、市场、财务、专利、论文、证书及工业硬件内容替换为链千言内容；
- 将用户提供的浅粉—浅蓝链环背景用于封面、关键机制页转场和结束页，正文页使用克制的局部品牌露出；
- 文字与流程、节点、架构图保持可编辑；真实产品截图以图片素材嵌入并按证据页使用；
- 不在 PPT 可见页面出现“AI辅助制作”，该标识只在后续佐证材料中处理；
- 不添加学校、教师、单位名称，不制造虚构用户、统计或产品结果。

## 真实素材与边界

优先使用项目已有的真实验证截图：学习诊断、知识空间、小涟对话/学习工作台、学习档案、我的成长路线、考试工作台和 Live2D 角色。对于项目当前真实的空态/未知态，保留其产品语义并配以简短说明：尚未评估不等于薄弱、无当前计划不等于系统故障、成长故事记录不足时不伪造时间线。

P8 的 46% → 51.5% 按用户文稿作为“动态重规划示例链路”呈现，不作为大样本统计结论。P14 保留“当前复述结果用于教学反馈，不直接修改 Mastery”的边界。P15 说明长期记忆主要基于学习证据与学习画像，部分复述仍属于本地状态。

## 交付与验收

- 最终文件为 20 页 `.pptx`，可在 PowerPoint 与 `F:\LibreOffice` 打开；
- 模板结构通过 artifact-tool 导入、复制和编辑；不以纯图片拼接方式替代可编辑内容；
- 每页逐页渲染为 PNG 检查标题、正文、截图裁切、连接线、页眉、占位符和边界说明；
- 使用 LibreOffice headless 转 PDF 作为第二条打开/导出验证链路；
- 运行模板保真检查、幻灯片溢出检查、PPTX 内部空占位符检查；
- 仅交付最终 PPTX，保留临时构建物在 `ppt_work_20260829`，不改动现有前端、后端或数据库代码。
