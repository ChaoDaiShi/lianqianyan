# 忆涟千言—教学习空间布局优化设计

日期：2026-08-29  
范围：React/Vite 前端呈现层与交互布局  
参考：`http://122.51.33.232` 的品牌入口结构与留白节奏

## 目标

在不改变现有账号、课程、学习计划、诊断、考试、资源、档案和小涟接口语义的前提下，降低页面的信息噪声，建立更清晰的品牌入口与学习工作区。用户首次进入时能快速理解“这里是什么”和“下一步做什么”；登录后能在一个稳定的应用外壳中进入今天的学习任务。

## 设计方向

采用“品牌首屏 + 聚焦内容”的结构：参考站点的大面积留白、强品牌识别和单一主行动，转译为忆涟千言—教的陪伴式学习入口。视觉基底使用用户提供的樱花、水波与云层图片；登录页完整使用图片作为背景，应用内使用低透明度背景并叠加可读性遮罩。配色以低饱和紫、夜色蓝、白色工作面和粉色点缀组成，避免高亮渐变、虚构数据和营销式指标。

## 页面结构

### 未登录入口

- 全屏背景图固定铺满视口，使用渐变遮罩确保表单和文字具有足够对比度。
- 中央或偏右放置白色/半透明登录卡，包含品牌标识、登录/注册切换、真实凭据字段、Turnstile（启用时）、提交按钮和内联错误状态。
- 背景左侧保留留白与水波视觉，不再额外叠加与项目无关的角色插画，避免两个视觉焦点竞争。
- 注册表单仅展示现有真实字段：显示名称、用户名、密码；不提供伪造的默认账号、默认计划或模拟成绩。
- 小屏幕将背景裁切到中心焦点，表单卡片变为近全宽，并保证键盘输入时不会被固定元素遮挡。

### 登录后应用外壳

- 顶部品牌栏保持固定但降低高度，左侧是“忆涟千言—教 / 小涟学姐”品牌入口，右侧是当前用户、工作台入口、设置和退出登录。
- 桌面端使用窄侧导航，图标与中文标签垂直排列；当前路由使用单一高亮底色，避免每个项目都变成强边框卡片。
- 移动端将侧导航转换为可横向滚动的底部导航，内容区为全宽并保留安全区间距。
- 主内容区统一最大宽度、顶部留白和响应式内边距；首页突出一个主任务，其余信息用低对比度摘要承载。
- 各页面继续使用现有 `AppShell`、`PageTransition`、`LearningRail` 和陪伴组件边界，不改变 API 调用或路由结构。

### 首页信息层级

1. 欢迎语与当前课程（真实账号/课程信息；未知时明确显示未选择）。
2. 今日主行动：当前任务或建立学习路线；无计划时显示真实的“尚未安排”状态和生成计划入口。
3. 诊断与最近学习证据摘要；未评估时显示 `--` 或“等待学习记录”，不推断薄弱点。
4. 进入小涟工作台和其他学习模块的次级入口。

## 组件与数据流

- `AuthScreen` 负责登录/注册视图与表单交互，继续通过 `AuthProvider` 调用真实 `login` / `register`。
- `AuthCompanionScene` 调整为背景层，不参与认证状态，不保存或生成业务数据。
- `AppShell` 负责全局底图、顶部栏、学习导航和页面容器；使用现有 `scene` 参数区分陪伴、星图和档案等页面氛围。
- 页面数据仍从现有 hooks 和 service 层读取；展示组件只消费已经加载的数据和明确的 `loading` / `error` / `empty` 状态。
- 主题切换继续由 `ThemeProvider` 管理；背景与表面颜色通过 CSS 变量和场景选择适配浅色/深色。

## 交互与错误处理

- 提交期间禁用主按钮，并显示当前动作（登录中/创建中）。
- 认证失败继续以内联 `role="alert"` 展示，不用 toast 覆盖用户输入。
- Turnstile 启用时保持提交前校验，认证失败后重置 token。
- `/api/plans/current` 的 404 视为“尚未建立路线”的真实空状态，不显示为网络故障，也不生成虚假路线。
- 未评估、无证据和接口未返回的指标使用 `--`、说明文案或占位状态，不显示为 0%。
- 所有按钮、导航和表单保留键盘焦点样式；尊重 `prefers-reduced-motion`。

## 验证范围

- 组件测试：登录/注册字段、切换、加载、错误和背景资源；应用外壳导航与响应式语义。
- 工程门禁：`pnpm check`、前端测试、`pnpm build`、`git diff --check`。
- 运行验证：本地启动后检查未登录入口、登录/注册切换、错误状态、课程选择入口、首页主要导航和桌面/移动视口无横向溢出。
- 发布前检查：确认只提交本次变更与当前分支中已经存在的用户改动；在目标分支上重新检查提交历史、远端同步状态和推送结果。

## 非目标

- 不新增或修改后端 API、数据库表、Agent、MCP 或支付逻辑。
- 不伪造账号、学习进度、诊断结果、知识关系、XP、连续学习天数或考试成绩。
- 不复制参考站点的代码、资源、品牌文案或第三方素材。
- 不清理、重置或覆盖当前工作区中已有的未提交改动。
