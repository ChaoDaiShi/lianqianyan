# 正式账号与空白学习空间设计

日期：2026-08-27  
状态：已接受（用户已授权全权负责并要求不再询问）

## 目标

平台从“匿名浏览器身份 + 固定默认课程”切换为正式账号体系。未登录用户只能看到登录/注册界面；新注册用户没有任何默认学习记录，必须先主动选择课程，之后才进入学习空间。已有匿名学习数据以备份优先的方式退役。

## 身份与数据模型

- 保留既有 `users` 表作为学习者领域身份，避免对已有 SQLite 表做不可迁移的原地字段变更。
- 新增 `auth_accounts`：账号 ID、规范化用户名、显示名、密码哈希、已选课程、失败次数、锁定时间和审计时间。
- 新增 `auth_sessions`：只保存随机会话令牌的 SHA-256 摘要、账号、过期时间和撤销时间。
- 注册事务同时创建 `auth_accounts` 与同 ID 的 `users` 记录。账号 ID 即全站 `learner_id`，不再生成 `anon:*`。

## 安全策略

- 密码使用 Python 标准库 `hashlib.scrypt`，每个账号独立随机盐；验证使用常量时间比较。
- 密码长度 8–128，至少包含字母与数字；用户名 3–32，只允许 Unicode 字母/数字及 `_-.`，以 `casefold` 规范化保证唯一。
- 登录失败统一返回相同错误；连续 5 次失败锁定 15 分钟。
- 会话令牌由 32 字节安全随机数生成，只通过 HttpOnly、SameSite=Lax Cookie 传输；默认 7 天过期，可通过环境变量配置 Secure。
- 业务 API 默认要求登录，CORS 允许凭据且仍使用明确来源白名单。
- 所有带 `learner_id` 的操作校验其等于当前账号 ID；课程范围必须等于账号已选择课程。共享课程目录、知识内容和题库定义保持公共目录语义。

## 用户流程

1. 首次打开：展示登录/注册页，不挂载业务路由，因此不会发起画像、计划或学习记录请求。
2. 注册成功：服务端创建账号和会话；用户仍没有课程、计划、证据、画像或考试记录。
3. 课程选择：展示服务端真实课程列表；用户主动选择后写入账号。
4. 进入平台：前端将非敏感账号 ID 和课程 ID 写入当前浏览器上下文，既有学习模块使用正式身份。
5. 退出登录：服务端撤销会话，前端清理身份和学习运行时状态，重新回到登录页。

## 前端结构

- `AuthProvider` 负责会话恢复、登录、注册、课程选择和退出。
- `AuthGate` 在身份确定前显示加载态；未登录显示账号页；未选课显示课程页；两者完成后才挂载现有 Router。
- `learnerContext` 不再创建、读取或接受匿名 ID；未登录使用不可路由哨兵值，由 AuthGate 阻止业务请求。
- API 客户端统一开启 `withCredentials`。
- 顶栏显示当前用户与退出入口。

## “移除默认学习”的定义

- 删除匿名 ID 自动生成与持久化。
- 删除前端默认课程作为学习身份的兜底；课程只有在账号明确选择后才有效。
- 注册不自动创建学习计划、任务、证据、掌握度、画像或考试尝试。
- 课程目录和知识点属于可选资源，不属于用户的“默认学习”，因此保留。
- 提供仅处理 `anon:*` 学习者数据的退役脚本：默认 dry-run，`--apply` 前自动备份数据库，绝不删除共享课程、知识点、题库和考试定义。

## 兼容与部署

- 生产默认启用认证；领域单元测试通过明确环境变量关闭认证，新增认证测试单独开启，避免把旧测试伪装成已登录。
- 前后端作为一个完整部署目录交付；静态前端与 FastAPI 同源部署时 Cookie 无需额外跨域配置。
- 版本提升到 1.4.0，并同步更新平台元数据、README、正式部署压缩包及校验信息。

## 验收标准

- 未登录访问业务 API 返回 401，健康检查与认证接口可访问。
- 注册、会话恢复、退出、错误密码、重复用户名、锁定策略均有自动化测试。
- 新账号注册后用户学习表为零；未选课不能访问课程型业务数据。
- 账号 A 无法读取或写入账号 B 的学习数据。
- 浏览器首次访问不展示任何默认学习；注册后必须选课；退出后无法回到业务页面。
- 退役脚本能备份并清理真实运行库中的匿名计划和任务，且共享目录保持不变。
- `pnpm check`、前端测试、后端测试、生产构建和真实 API/浏览器流程全部通过。
