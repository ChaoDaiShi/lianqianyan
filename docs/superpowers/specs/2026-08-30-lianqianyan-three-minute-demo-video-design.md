# 涟千言三分钟比赛演示视频设计

## 1. 目标与硬性约束

为当前涟千言 React/Vite + FastAPI 产品制作一支可直接提交比赛的完整演示视频。视频必须直观展示作品功能、操作流程和实际运行效果，并满足以下硬指标：

- 容器格式：MP4。
- 目标时长：2 分 48 秒至 2 分 52 秒；硬上限低于 3 分钟。
- 目标分辨率：1920×1080，16:9，30 fps。
- 文件大小：目标 35–90 MB，硬上限 200 MB。
- 声音：MiniMax 异步长文本语音合成，配合清晰字幕；无爆音、削波或明显底噪。
- 画面：真实浏览器操作和真实前后端响应；不使用静态概念图冒充功能结果，不制造学习成绩、计划、知识关系或资源生成结果。

## 2. 方案比较与选择

### 方案 A：单镜到底

连续录制一次从登录到学习结束的完整操作。真实性最直观，但三分钟内容纳不下全部功能，网络或模型等待也容易造成节奏失控。

### 方案 B：真实流程分段录制后剪辑（采用）

把登录、学习闭环、知识星图、考试、资源生成、小涟对话和设置分成独立真实录制段。每一段均来自实际运行，只删除等待、鼠标寻找和无信息停顿，再用旁白和字幕串成一条连续叙事。该方案兼顾真实性、可读性、时长和失败重录成本。

### 方案 C：功能截图与宣传动效

使用静态页面截图、标题和装饰动画快速覆盖功能。画面容易精致，但不能充分证明“实际运行效果”，不符合本次比赛要求。

最终选择方案 B。视频不展示终端、测试输出或制作过程，评委只看到完整产品界面和关键操作反馈。

## 3. 叙事结构与分镜

### 0:00–0:08 开场与定位

- 涟千言品牌画面和一句价值主张。
- 直接进入登录界面，不使用长片头。

### 0:08–0:27 正式账号与学习首页

- 真实输入演示账号并登录。
- 进入首页，展示当前课程、今日任务和小涟陪伴入口。
- 进入“我的学习”，展示当前计划与任务路径。

### 0:27–1:15 AI 陪伴式学习闭环

- 从真实计划任务进入学习空间。
- 展示任务目标、阶段轨和学习上下文。
- 向 Tutor 提出一个与课程知识点相关的问题并展示回答。
- 完成一道真实练习，展示即时反馈、学习证据写入和下一步引导。
- 通过页面反馈体现证据驱动诊断和动态重规划，不伪造前后对比数值。

### 1:15–1:38 学习诊断与知识星图

- 进入学习诊断或知识空间。
- 展示知识星图的真实节点与关系。
- 真实执行缩放、拖动、选中节点，打开知识点详情或溯源信息。
- 未评估或证据不足状态保持 `--` 或产品既有诚实表达。

### 1:38–1:58 考试中心

- 进入考试中心，展示题库/组卷/测评入口。
- 打开或开始一次真实测评，完成一道题并展示提交反馈或结果页。
- 不把尚未运行的 AI 组卷结果当作已完成成果。

### 1:58–2:25 学习工坊与资源产出

- 输入真实资源目标并触发资源生成。
- 展示生成进度、真实内容预览和配图/联网检索状态。
- 展示 PPT 或资源导出按钮与实际下载结果；若云端模型本次不可用，则使用此前已由真实流程生成且可校验的本地成品，并在画面中避免声称为“本次实时生成”。

### 2:25–2:41 小涟对话与数字人

- 进入小涟对话，发送一条真实问题。
- 展示 Agent 回答、来源/工具信息和语音播放。
- 展示 Live2D 运行或口型联动效果；MiniMax 视频旁白与产品内语音不同时播放，避免混音混乱。

### 2:41–2:50 档案、设置与收束

- 快速展示学习档案/学习产物和设置分区。
- 以“计划—学习—证据—诊断—调整”的闭环图文收束。
- 片尾不超过 2 秒。

## 4. 真实数据与操作边界

- 使用单独的本地演示账号和演示会话，所有页面调用真实本地 API。
- 优先通过产品自身注册、计划生成、练习提交、考试作答和资源生成流程产生演示数据。
- 若验证码阻碍无人值守录制，在隔离的演示运行环境中关闭验证码，但不绕过账号密码认证、不修改生产数据库，也不声称演示了线上验证码验证。
- 若必须准备可重复的初始数据，使用真实业务 API 或服务层建立；不直接伪造前端状态。
- 录制使用独立浏览器配置目录；录制结束后清理临时会话和浏览器配置，不删除用户现有数据。
- 当前工作区的未提交代码、PPT 和数据库均为用户状态；禁止 reset、clean、覆盖或合并数据库。

## 5. MiniMax 异步配音流程

1. 依据最终镜头长度编写约 600–700 个汉字的中文旁白，避免连续堆术语。
2. 使用当前后端配置中的 MiniMax API Key、模型和 Voice ID；密钥只从环境文件加载，不写入脚本、日志或成品。
3. 调用异步 TTS 创建接口取得 `task_id`。
4. 以有限重试和退避轮询任务状态；成功后取得 `file_id`。
5. 在官方文件有效期内立即下载 MP3/WAV 到本地演示产物目录。
6. 检查音频可解码、时长、声道、峰值和响度；必要时只调整语速或重生成旁白，不通过截断句尾强行对时。
7. 生成烧录字幕，并保留旁白原文与任务元数据（不含密钥）作为交付证据。

## 6. 录制与合成架构

- 浏览器录制：使用 Chromium/Chrome 的自动化录制能力，固定 1920×1080 视口、100% 缩放和干净浏览器配置。
- 操作脚本：按分镜拆成可独立重录的场景；定位使用可访问名称、文字和稳定选择器，不依赖屏幕绝对坐标。
- 原始素材：每个场景保存视频片段、关键截图、操作日志和失败日志。
- 剪辑：裁掉加载等待和无信息停顿，使用简洁硬切/短交叉淡化；不对真实结果做替换或合成。
- 字幕：底部安全区内的简体中文字幕，最多两行；界面关键区域被遮挡时自动上移。
- 音频：旁白为主，产品内语音只在小涟段短暂保留；背景音乐默认不加入，避免版权与清晰度风险。
- 编码：H.264 + AAC，`yuv420p`，faststart；按最终时长控制视频码率，确保远低于 200 MB。

## 7. 异常处理

- 外部 LLM、MiniMax、AnySearch 或图片生成失败时，先有限重试；仍失败则缩短该镜头并真实展示降级状态，不伪造成功。
- 浏览器操作因响应速度变化而超时时，只重录对应场景，不重放已经完成的业务写操作。
- 若成片超过 2:55，优先压缩转场、停顿和次级功能镜头，不加速旁白到难以听清。
- 若文件超过 180 MB，重新编码降低视频码率；不降低到影响文字辨识的分辨率。
- 若字幕遮挡关键控件，按场景调整字幕位置，不永久缩小界面。

## 8. 验收与交付物

最终交付目录包含：

- `涟千言_三分钟功能演示.mp4`：比赛提交成片。
- `涟千言_三分钟功能演示.srt`：独立字幕。
- `旁白稿.md`：最终 MiniMax 旁白文本与镜头对应表。
- `video-manifest.json`：分辨率、编码、时长、文件大小、SHA-256 和录制场景清单，不含任何密钥。
- `verification.md`：实际运行、音频下载、视频技术指标、人工画面/声音复核结果和任何真实降级说明。

验收必须同时满足：

1. `ffprobe` 或等价媒体探测确认 MP4 可解码，时长小于 180 秒，1920×1080，H.264/AAC。
2. 文件系统确认大小小于 200 MB，并记录 SHA-256。
3. 抽帧检查开头、各功能段、字幕和片尾，无黑帧、花屏、登录信息泄露或遮挡。
4. 完整播放检查旁白无缺句、字幕同步、语音清晰，界面文字在 1080p 下可辨认。
5. 功能清单逐项映射到成片时间码；只把真实运行成功的能力标记为已演示。
6. 按项目契约运行 `pnpm check`；视频制作脚本另做语法/干运行检查。

## 9. 明确不做

- 不在三分钟内逐按钮穷举所有高级设置。
- 不展示源代码、命令行、单元测试或开发日志来替代产品功能。
- 不购买素材、不使用有版权风险的背景音乐。
- 不修改远端部署、生产数据库或用户现有账号。
- 不把等待剪掉后的片段描述为实时生成速度证明。
