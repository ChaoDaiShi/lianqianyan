## 为什么要分层

网络通信涉及布线、寻址、可靠传输、应用格式等差异巨大的问题。分层把整体问题拆成若干只依赖下层服务、只对上层提供服务的独立层次，每层专注自己的职责并通过接口交互。分层带来的好处是标准化的接口允许不同厂商设备互通、某一层技术升级不影响相邻层，例如以太网更换为 Wi-Fi 时上层协议无需修改。代价是每一层的封装会带来额外的头部开销。

## OSI 七层模型

OSI 从下到上依次为物理层、数据链路层、网络层、传输层、会话层、表示层和应用层。物理层关心比特流在介质上的传输，涉及电平、接口形状和传输速率；数据链路层把比特组织成帧，负责相邻节点间的可靠传递、差错检测和 MAC 寻址；网络层负责逻辑寻址与路由选择，把分组从源网络送到目的网络；传输层提供端到端的进程间通信；会话层建立、管理和终止会话；表示层处理数据格式转换、加密与压缩；应用层直接为用户应用提供服务。

## TCP/IP 模型与对应关系

实际互联网采用 TCP/IP 模型，通常划分为四层：网络接口层、网际层、传输层和应用层。它与 OSI 的对应关系是：网络接口层覆盖物理层与数据链路层，网际层对应网络层（核心协议 IP），传输层对应传输层（TCP 与 UDP），应用层合并了会话、表示与应用三层（HTTP、DNS、FTP、SMTP 等）。考试常考"某设备/协议工作在哪一层"：中继器和集线器在物理层，网桥和交换机在数据链路层，路由器在网络层。

## 数据封装与解封装

发送方数据自上而下逐层加头（部分层还加尾）形成帧或分组：应用数据交给传输层加 TCP/UDP 头成为段，交给网际层加 IP 头成为包，交给网络接口层封装成帧最后变成比特流。接收方自下而上逐层去头还原。理解封装的关键是记住每层头部携带本层需要的地址：帧用 MAC 地址，包用 IP 地址，段用端口号。协议数据单元的记忆口诀是"比特、帧、包、段、数据"。

## 常见考点与自测

常见考点包括：给出设备或协议判断所属层次；比较 OSI 与 TCP/IP 的层次差异；解释分层的优点与封装过程。易错点是把交换机当作网络层设备（普通交换机是二层设备，三层交换机才具备路由能力），以及认为 TCP/IP 有会话层。自测应能回答：OSI 七层从下到上依次是什么？路由器工作在哪一层？TCP 头中用于标识进程的字段叫什么？
