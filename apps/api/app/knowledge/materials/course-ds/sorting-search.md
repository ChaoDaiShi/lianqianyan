## 查找的基本概念与顺序、折半查找

查找表上的基本操作是按关键字定位记录。平均查找长度 ASL 是衡量算法的标准：顺序查找对 n 个元素等概率下 ASL=(n+1)/2，对存储方式无要求，有序无序都可以。折半查找要求顺序存储且关键字有序，每次与中间元素比较使区间减半，比较次数不超过 ⌊log2 n⌋+1，等概率下 ASL≈log2(n+1)−1。判定树是分析折半查找的工具：n 个元素的判定树形态唯一，与完全二叉树高度一致。

## 二叉排序树查找与哈希查找

二叉排序树的查找从根出发，小于根走左子树、大于根走右子树，平均 O(log n)、最坏 O(n)。哈希查找通过散列函数直接由关键字计算存储地址，理想情况 O(1)。冲突不可避免，处理开放定址法中的线性探测（容易堆积）、二次探测与链地址法（同义词挂链，无堆积且便于删除）。负载因子 α=表中记录数/表长，α 越大冲突越高。构造散列函数常用除留余数法 H(key)=key mod p，p 取不超过表长的最大素数。

## 简单排序：插入、冒泡与选择

直接插入排序把每个新元素插入已排序前缀，最好情况（已有序）只需 n−1 次比较、时间 O(n)，平均 O(n²)，稳定，基本有序时效率高。冒泡排序相邻逆序交换，加提前结束标志后最好也是 O(n)，平均 O(n²)，稳定。简单选择排序每轮从未排序区间选最小者放到前面，比较次数固定 n(n−1)/2，时间恒为 O(n²)，不稳定（如序列 3,3,1 会改变相等元素相对次序）。

## 改进排序：希尔、快排、堆排与归并

希尔排序按增量分组做插入排序，增量逐趟缩小到 1，突破 O(n²) 达到约 O(n^1.3)，不稳定。快速排序取枢轴将区间划分为两部分递归处理，平均 O(n log2 n) 且常数最小，是最快的通用比较排序；最坏（基本有序时）退化为 O(n²)，不稳定。堆排序先用无序序列建大根堆，反复取堆顶与末尾交换再调整，建堆 O(n)、每次调整 O(log2 n)，整体 O(n log2 n)，不稳定，适合大规模数据且无最坏退化。归并排序两两合并有序段，稳定、恒为 O(n log2 n)，需要 O(n) 辅助空间。

## 排序比较与自测

判稳口诀：插入、冒泡、归并稳定；选择、希尔、快排、堆排不稳定。空间：归并 O(n)、快排平均 O(log2 n)（递归栈）、其余 O(1)。常考场景：基本有序选插入或冒泡；要求稳定且 O(n log2 n) 选归并；大规模随机数据选快排或堆排；只求最快且不稳定可接受选快排。常见误区包括：把折半查找用于链表（不能随机访问）；认为哈希查找与关键字比较次数无关（冲突时仍需探测比较）；记错稳定的算法集合。自测应能回答：给出序列手工写出一趟快排结果；画出 3 个元素折半查找判定树；说明堆排建堆与调整过程；比较各类排序的时间、空间与稳定性。
