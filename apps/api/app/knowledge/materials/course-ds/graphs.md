## 学习目标

- graph-terms-representations：区分有向/无向、带权/无权图术语，并比较矩阵与邻接表。
- graph-traversal：按显式邻接扫描顺序推演 BFS/DFS 并分析成本。
- graph-spanning-path：区分生成树、最小生成树和最短路径的目标及条件。
- graph-dag-order：对 DAG 做拓扑排序并计算关键路径。

## 基本术语与表示

图 G=(V,E) 由顶点和边组成。有向图边有起点和终点；无向图边没有方向。顶点的无向度是关联边数；有向图分别有入度与出度，二者之和常称总度。以下复杂度默认不含平行边与自环；若允许自环，度数是否将自环计两次需按题目约定。

邻接矩阵为 V×V 矩阵，访问一对顶点是否相邻为 O(1)，空间 Θ(V²)。对有向图，行和表示出度、列和表示入度；对无向简单图，矩阵对称，行和表示度。矩阵中的扫描顺序取决于程序按什么顶点索引迭代。
邻接表对每个顶点保存其邻居列表，空间 Θ(V+E)；无向边通常在两端邻接表各存一次。枚举一个顶点的邻居与其度数成正比。稀疏图通常更省空间；稠密图下矩阵的直接访问和连续存储可能更合适。
## BFS、DFS 与遍历次序
DFS 沿一条未完成路径深入，再回溯，使用递归调用栈或显式栈。BFS 先处理当前距离层的已发现顶点，再扩展下一层，使用 FIFO 队列。邻接表表示下，覆盖所有连通分量的 DFS/BFS 为 Θ(V+E)；邻接矩阵扫描邻居通常为 Θ(V²)。
遍历序列不由图本身唯一决定。邻居访问顺序变化时，合法 BFS/DFS 次序可能改变；若实现固定顶点索引扫描、图与起点也固定，输出才会在该实现下确定。BFS 在无权图或边权相同的图中给出最少边数路径；一般带权图不能用 BFS 代替最短路算法。
### 例一：扫描顺序影响 BFS
无向图有边 A-B、A-C、B-D、C-D，从 A 开始。若 A 的邻居按 B、C 扫描，BFS 次序可以是 A,B,C,D；若按 C、B 扫描，则可以是 A,C,B,D。两种都满足按距离层次访问；矩阵本身不会让第一种序列成为唯一答案。
## 生成树、最短路径
生成树只针对连通无向图，包含所有顶点并连通且无环，因此有 V−1 条边。最小生成树（MST）在满足这些条件的树中最小化所选边的权值总和；权值可以为负。Prim 按当前树到树外顶点的最小连接边扩展；Kruskal 按边权从小到大考察，并跳过会形成环的边。
最短路径优化的是指定起点到目标的路径成本，不是整棵树的边权总和。Dijkstra 的标准贪心算法要求边权非负；含负边时不能保证正确，可在无负回路的条件下使用 Bellman-Ford。Floyd-Warshall 求全点对最短路，允许负边但不允许负回路，时间 Θ(V³)。
### 例二：MST 路径不一定最短
三角形顶点 A、B、C 的边权为 AB=2、BC=2、AC=3。MST 选 AB 与 BC，总权值为 4；但 A 到 C 的直接最短路权值为 3。沿 MST 从 A 到 C 的树路径要经过 B，成本为 4。最小生成树和最短路径树解决不同优化目标。
## 拓扑排序与关键路径
拓扑序只对有向无环图（DAG）定义：每条有向边的起点都排在终点之前。Kahn 算法反复取入度为 0 的顶点输出，并删除其出边。若未输出完所有顶点，则剩余部分有环；若某一步有多个入度为 0 的选择，可能存在多个合法拓扑序。
AOE 网以边表示带工期的活动。令 ve[j]=max(ve[i]+duration(i,j)) 计算最早事件时间；从项目工期倒推 vl[i]=min(vl[j]−duration(i,j)) 得最迟事件时间。边 i→j 的最早开始 ES=ve[i]，最迟开始 LS=vl[j]−duration(i,j)；ES=LS 的活动为关键活动。缩短非关键活动不必然缩短工期。
### 例三：拓扑序不唯一与成环
DAG 中只有 A→C、B→C 时，A、B 入度都为 0；可先输出 A 再 B，也可先 B 再 A，故拓扑序不唯一。若再加 C→A，剩余顶点构成环，Kahn 队列最终为空且不能输出所有顶点。
## 复杂度对照
| 操作 | 常见成本 | 条件 |
| --- | --- | --- |
| 判邻接矩阵一对顶点 | O(1) | 矩阵已建立 |
| 邻接表 DFS/BFS | Θ(V+E) | 遍历全图且记录 visited |
| 邻接矩阵 DFS/BFS | Θ(V²) | 每个顶点扫描一整行 |
| Kahn 拓扑排序 | Θ(V+E) | 邻接表和入度表 |
| Floyd-Warshall | Θ(V³) 时间、Θ(V²) 空间 | 全点对最短路 |
| Kruskal | 排序为主，O(E log E) | 连通无向带权图；常配并查集判环 |
Prim 的实现成本依赖选取最小边的数据结构：朴素矩阵实现常为 O(V²)，使用堆则可降低稀疏图上的成本。应写明实现假设，不把“适合稠密/稀疏”当作脱离实现的定理。
## 常见误解与边界
- 邻接矩阵行和仅在有向图表示出度；无向图简单情况下行和为度。
- 邻接矩阵遍历次序可受顶点扫描次序影响；图并不保证唯一序列。
- BFS 最少边数性质不等同于一般非负带权最短路。
- MST 最小化树边权和，不保证树上任意两点的路线最短。
- 拓扑序唯一性需逐步确认零入度候选是否唯一；“有一个拓扑序”不代表唯一。
- Dijkstra 负边条件、Floyd 负环条件要分开记。
## 自测提示
作图题先标方向、权值、顶点顺序和邻接扫描顺序。算遍历时同步维护 visited。最短路与 MST 先写目标函数，再核对算法前提。拓扑排序时每轮列出所有可选零入度点。
